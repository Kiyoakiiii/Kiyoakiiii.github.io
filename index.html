Research

Tactile Manipulation Lab, UC Santa Cruz

Sep 2025 – Present

Graduate Researcher · Autonomous Tomato Seedling Transplantation

  • Building an end-to-end Python pipeline from ZED 2i RGB-D capture to a Franka Research 3, demonstrating stem-based acquisition, tray extraction, transport, and placement in initial end-to-end trials.
  • Annotated main-stem instance masks on 200+ RGB-D images with plant/session-level splits to prevent leakage; fine-tuned an Ultralytics YOLO segmentation model and skeletonized masks into centerlines to pick long, low-curvature grasp segments.
  • Recovered 3D stem position and tangent from point clouds with confidence and depth-discontinuity filtering followed by RANSAC + PCA line fitting; converted results to robot-frame grasp poses using calibrated camera-to-base transforms.
  • Generated side-approach grasp candidates filtered by workspace, inverse kinematics, and gripper–tray clearance, ranked by depth quality and capture tolerance.
  • Implemented a fault-tolerant task state machine over franky/libfranka (observe → validate → pre-grasp → acquire → extract → transport → place → recover) with wrench-based contact detection, re-observation, bounded retries, and retreat.
  • Measured gripper capture tolerance under controlled 3-axis offsets, separating holding failures from extraction resistance, to set localization accuracy requirements for the perception stack.
