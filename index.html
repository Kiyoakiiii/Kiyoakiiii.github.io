Graduate Researcher · Tactile Manipulation Lab, UC Santa Cruz

05 · ACTFranka FR3State machine with contact-aware recovery
  • Demonstrated stem-based acquisition, tray extraction, transport, and placement in initial end-to-end trials on a Franka Research 3 with a rubber-padded gripper.
  • Annotated main-stem instance masks on 200+ RGB-D images with plant/session-level splits to prevent leakage; fine-tuned an Ultralytics YOLO segmentation model and skeletonized masks to select long, low-curvature grasp segments.
  • Recovered 3D stem position and tangent from ZED SDK point clouds, filtering low-confidence and depth-discontinuity pixels before RANSAC + PCA line fitting; debugged geometry in Open3D.
  • Calibrated camera-to-base and tool-to-contact transforms; generated side-approach grasps perpendicular to the stem, filtered by workspace, inverse kinematics, and gripper–tray clearance.
  • Built a Python state machine over franky/libfranka with bounded velocity/acceleration/jerk, external-wrench contact detection, re-observation, bounded retries, and retreat.
  • Measured gripper capture tolerance under controlled 3-axis offsets, isolating slippage from extraction resistance to set localization requirements for perception.
