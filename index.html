Research

Autonomous Tomato Seedling Transplantation

Sep 2025 – Present

Graduate Researcher · Tactile Manipulation Lab, UC Santa Cruz

RGB-D capture→ Stem segmentation→ 3D line fitting→ Grasp planning→ Franka FR3 execution
  • Demonstrated stem-based acquisition, tray extraction, transport, and placement in initial end-to-end trials on a Franka Research 3 with a fixed ZED 2i camera.
  • Annotated main-stem instance masks on 200+ RGB-D images with plant/session-level splits to prevent leakage; fine-tuned an Ultralytics YOLO segmentation model and skeletonized masks to select long, low-curvature grasp segments.
  • Recovered 3D stem position and tangent from point clouds, filtering low-confidence and depth-discontinuity pixels before RANSAC + PCA line fitting.
  • Calibrated camera-to-base and tool-to-contact transforms; generated side-approach grasps filtered by workspace, inverse kinematics, and gripper–tray clearance.
  • Built a Python state machine over franky/libfranka with bounded motion limits, wrench-based contact detection, re-observation, bounded retries, and retreat.
  • Measured gripper capture tolerance under controlled 3-axis offsets to set localization requirements for the perception stack.
